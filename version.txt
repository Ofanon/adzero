# AdZero — latest published version
#
# The app reads this once a day and tells the user when a newer build exists.
#
# This is not a nicety: an app installed by hand has no update mechanism at
# all. Somebody who received AdZero over WhatsApp has whatever version was
# current that day, for ever, and will never learn that anything changed —
# including the fix for the bug that annoys them.
#
# Two lines to change per release. Anything else is ignored.
#
#   code=<versionCode>    must match app/build.gradle.kts exactly
#   name=<versionName>    what the banner shows the user
#
# There is deliberately no address to keep in step. The banner opens
#
#   github.com/Ofanon/adzero/releases/latest/download/AdZero.apk
#
# which GitHub redirects to the newest release on its own. It holds no version
# number, so it never goes stale — that is why it lives in Remote.kt and not
# here. Attaching the build to the release under the name AdZero.apk, exactly,
# is the whole of what makes it work; the build produces that name by itself.
#
# The browser downloads the file and the user opens it. AdZero does not ask
# Android for permission to install applications: that permission is the first
# thing an antivirus looks at on an app distributed outside a store, and it
# would have saved a single tap.
#
# url=<link>  overrides the address above, and normally stays absent. It is the
# way out if a release ever has to be pulled or the repository moves, since
# older copies of the app cannot be edited. Only github.com/Ofanon/adzero/ is
# accepted.
#
# Bump code only once the release is actually published. A banner pointing at a
# 404 is worse than no banner.

code=2
name=1.0
